# 作业管理：导出作业海报图片

## Context

管理员需要在「作业管理」把当前日期已经发布的全部作业合成一张排版美观的图片，用于分享或留存。操作链路为：点击「导出图片」→ 自动生成高清 PNG → 浮窗预览 → 点击「下载图片」。不改动作业数据和后端接口。

## 实现方案

### 1. 原生 Canvas 海报生成器

新增 `src/lib/poster.js`，导出 `createHomeworkPoster(board, settings)`，返回 PNG `Blob`。

- 使用当前 `/api/board` 已加载的数据，保留后端科目排序；仅允许 `board.published === true` 时导出。
- 采用适合手机查看和分享的竖版浅色海报：深蓝渐变页眉、班级名称与日期/星期、作业数量、白色圆角作业卡片、底部品牌与提示文字。
- 作业卡片复用 `subjectColor()` / `subjectInitial()`，展示序号、科目、加急标识、课时截止、完整作业内容、备注和附件名称。
- 先测量后排版：按字符和显式换行处理中英文长文本，依据每张卡片实际内容动态计算画布总高度，避免内容裁切或重叠。
- 以约 750 逻辑像素宽、2 倍像素比输出高清 PNG；绘制前等待浏览器字体就绪，并设置可靠的中文字体回退。

### 2. 作业管理入口与预览浮窗

修改 `src/views/admin/AdminHomework.vue`：

- 在现有工具栏的发布操作旁加入「导出图片」按钮，导出口径为当前选中的日期（默认今天）。
- 草稿状态提示先发布；无作业时提示无可导出内容；生成期间按钮显示加载状态并防止重复点击。
- 生成成功后复用 `Modal.vue` 打开大尺寸浮窗，展示完整图片预览，并提供「下载 PNG 图片」主按钮；附一句手机端可长按图片保存的提示。
- 下载文件名使用 `班级-YYYY-MM-DD-作业清单.png`；通过临时对象 URL 和带 `download` 的链接触发下载。
- 关闭浮窗、重新生成和组件卸载时释放旧对象 URL，避免内存泄漏。
- 为预览区补充局部样式，使桌面端清晰、手机端完整可见，长图可在浮窗内滚动。

### 3. 复用现有能力

- 日期与星期：`src/lib/format.js` 的 `formatDateCN()`、`weekdayCN()`。
- 班级/站点文案：`src/lib/store.js` 的 `state.settings`。
- 提示与弹窗：`pushToast()`、`Modal.vue`、`Icon.vue`。
- 不引入 html-to-image、canvas 等第三方依赖，不修改 `server/`。

## 验证

1. 执行 `npm run build`，确认 Vue 模板与海报工具无编译错误。
2. 浏览器验证已发布作业：导出按钮生成图片并先弹窗预览，预览与下载文件一致，PNG 可正常打开。
3. 验证排版：中文、英文、换行、长内容、多个附件、加急与课时字段完整展示，多科目顺序与作业管理一致。
4. 验证边界：草稿、空作业、连续打开/关闭、切换日期后重新导出，以及窄屏浮窗与下载操作。
